# Guided learning workflow

This repository is a learning project. The owner wants small, understandable steps and hopes to finish mandatory scope in three days.

- Read README.md and documentation/PLAN.md before changes.
- Explain only the current concept using plain language and a small example.
- Implement one agreed learning step at a time. Do not build the full project unsolicited.
- Reuse the owner's existing ERC-20 and ERC-721 work after inspecting it.
- Follow the required code/, frontend/, deployment/, documentation/ structure.
- Write meaningful contract tests for accounting, access control and external-call behavior.
- Never commit secrets, private keys or real wallet credentials.
- Keep NFT payments separate from liquidity reserves.
- Keep the plan honest about completed work and remaining verification.
